# Proyecto Django con PostgreSQL

## Descripción
Este proyecto utiliza Django para desarrollar una aplicación web conectada a una base de datos PostgreSQL.

## Tecnologías utilizadas
- Python
- Django
- PostgreSQL
- Git y GitHub

## Estructura del proyecto
- `manage.py`: permite ejecutar comandos de Django.
- `desafiodb/`: contiene la configuración principal del proyecto.
- `testdb/`: contiene la aplicación y el modelo de datos.

## Modelo de datos
La aplicación incluye el modelo `AdlTest`, que contiene los campos `campo1` y `valor1`.

## Buenas prácticas
- Organizar el código en aplicaciones.
- Utilizar Git para registrar los cambios.
- Mantener fuera del repositorio las contraseñas y otros datos sensibles.
- Documentar el propósito y la estructura del proyecto.

## Ejecución
Para ejecutar el proyecto, instala las dependencias necesarias, configura la conexión a PostgreSQL y utiliza `python manage.py runserver` desde la terminal.
